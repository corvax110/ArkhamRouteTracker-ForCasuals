# ArkhamRouteTracker For Casuals
Tool to help learn 100% speedruns for all four main-series Batman Arkham games.

Route trackers for each game originally created by oneeyeddeacon.

My changes are done because i am an insane person and follow along the speedrun routes when i play, and i wanted to customize a couple things to help with my significantly more casual run.

Things added:

-Updated the Knight240 route file to fix image links

-Added Image Display functionality along with an Image cache

-Image Cache has a dedicated management window, can cache all images of a route at once
  
-added Ignore List, User can right click an entry in the list to add it to an ignore list (treated as complete)

  ---can go into preferences to find a Clear Ignore List button
